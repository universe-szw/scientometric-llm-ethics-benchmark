# Small examples

These files contain two linked cases from the released Content Safety CSVs:

- `benchmark_sample.csv`: CS-001 and CS-002 from `dataset/content_safety.csv`.
- `responses_sample.csv`: the matching Claude Sonnet 4 run-1 responses from `model_responses/content_safety_responses.csv`.
- `scores_sample.csv`: the matching GPT-5.5 scores from `scoring_results/gpt55_scores.csv`.

All field values are copied unchanged; CSV quoting and line endings may differ. These are examples for inspecting schemas and running offline checks. They are not additional experimental observations or a representative evaluation subset. The complete published records remain in the original directories.
