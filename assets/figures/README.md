# Figure provenance

These files are unchanged copies of the author-prepared artwork for Figure 1, "Mean automated scores across five evaluation dimensions," in Shen et al. (2026), *Scientometrics*, 131, 7001-7024. DOI: https://doi.org/10.1007/s11192-026-05773-0.

The figure shows eight model families and five ethical dimensions. Scores are averaged across three runs for each model and dimension, using the original fixed 0-10 color scale. It is the published evaluation result, not a new analysis or an updated leaderboard.
